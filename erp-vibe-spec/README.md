# ERP Vibe Spec

Repositorio dedicado exclusivamente a especificaciones y documentación para el ecosistema ERP multi-tenant. No incluye código de aplicación; solo contiene contexto arquitectónico, metadata en YAML y prompts para agentes de IA.

## Cómo usar
- Lee los documentos en `docs/` para entender la arquitectura, dominios y componentes técnicos.
- Consulta `metadata/` para revisar definiciones de dominios, entidades y casos de uso en formato YAML.
- Usa los prompts en `ai/` (agentes, políticas y contextos) como entrada para herramientas de IA que generarán código en los repositorios de implementación.
- Mantén separado este repositorio de cualquier código fuente; es la fuente de verdad de especificaciones en estilo vibe coding.
